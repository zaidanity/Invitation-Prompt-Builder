# 💍 Invitation Prompt Builder – Wedding Prompt Studio

[![GitHub Repo stars](https://img.shields.io/github/stars/zaidanity/Invitation-Prompt-Builder?style=social)](https://github.com/zaidanity/Invitation-Prompt-Builder)

**Generator pembuatan undangan digital** yang mengubah detail pernikahan Anda menjadi **prompt profesional** siap kirim ke developer atau AI.

> ✨ AI‑ready · frontend brief

## 🎯 Apa Itu Ini?

Website ini membantu Anda menyusun *brief* undangan digital dengan cara yang rapi dan terstruktur. Cukup isi data pernikahan (nama, tanggal, tema, dll.), lalu dapatkan prompt siap pakai untuk:

- Developer undangan digital
- AI seperti ChatGPT, Claude, atau Midjourney
- Desainer grafis

## ✨ Fitur Utama

- 📝 **Formulir detail pernikahan** – lengkap dan mudah diisi
- 🤖 **Generator prompt otomatis** – output langsung siap salin
- 🖼️ **Dukungan Google Drive** – gunakan format `https://lh3.googleusercontent.com/d/ID_FOTO`
- 📱 **Tampilan responsif** – works on mobile & desktop
- 🎨 **Desain minimalis** – fokus pada fungsionalitas

## 🛠 Teknologi

Berdasarkan repository:

- **HTML5** – 100% (single page)
- **CSS3** – styling kustom
- **JavaScript** – logika generator prompt
- **Vercel** – hosting dan deployment

## 💻 Menjalankan Lokal

Karena ini adalah website statis (HTML/CSS/JS), Anda bisa langsung:

```bash
# Clone repositori
git clone https://github.com/zaidanity/Invitation-Prompt-Builder.git

# Buka folder
cd Invitation-Prompt-Builder

# Buka index.html dengan browser
open index.html   # atau double-click file-nya
```

Atau gunakan Live Server di VS Code untuk pengalaman development yang lebih baik.

📝 Contoh Output Prompt

Setelah mengisi data, sistem akan menghasilkan prompt seperti:

```text
Buatkan undangan pernikahan digital untuk Andi & Sarah. 
Tanggal: 20 September 2025. 
Tema: Rustic elegant. 
Lokasi: Hutan Kota, Bandung. 
Warna utama: Sage green & cream. 
Sertakan peta lokasi, link RSVP, dan galeri foto. 
Background: bunga kering dan nuansa natural.
Gunakan format Google Drive untuk foto: 
https://lh3.googleusercontent.com/d/ID_FOTO123
```
